# Council v1 is a descriptive race card, not a probabilistic forecast

ADR 0009/0012/0019/0025/0026/0027 design a candidate-level probabilistic Council Forecast — Incumbent Defeat, Close-Result, and challenger Candidate Win probabilities, gated by a C-tier evidence ladder and validated on whole cycles. With the Mayoral Endpoint qualified, the natural next step was to build the council equivalent. Before doing so, a signal search ([council-defeat-beyond-cdi.md](../research/council-defeat-beyond-cdi.md)) tested whether an incumbent-defeat probability could actually validate. It cannot, and this ADR fixes the consequence: **Council v1 publishes no predictive probability.**

The evidence is decisive and structural, not a matter of model choice. The `defeatability-index` project already establishes that Matt Elliott's equal-weight CDI is a **weak screen** (defeat-prediction AUC 0.643, 95% CI [0.485, 0.782] — straddling chance) and that *fitting* weights scores worse than a coin flip out-of-fold. The signal search then tested the four avenues that could plausibly beat it — challenger quality, field size/fragmentation, multi-cycle incumbent trajectory, and mayoral coattails — against a pre-registered bar (a robust, consistent lift on the boundary-stable ex-2018 cycles that 2026 resembles, and a signal that fires in enough 2026 wards to matter). **All four are null or negative ex-2018.** The apparent challenger-quality lift is entirely the non-recurring 2018 ward merger; mayoral coattails are triply barred (ADR 0014, citywide-only 2026 mayoral evidence that cannot differentiate wards, and no ward-level historical mayoral data to learn from). The root cause is a data ceiling no feature can clear: **5–7 incumbent defeats across four normal cycles (5.7% base rate)**, with bootstrap intervals so wide the CDI itself cannot be distinguished from chance. A calibrated incumbent-defeat probability is therefore unvalidatable for 2026, and ADR 0026's stratified gate would correctly return Forecast Unavailable.

**Council v1 instead ships a per-ward race card built entirely from Observed Evidence and an already-validated screen.** For each race: candidate **electoral biographies** — prior offices, appearances, results — from the Officeholding-History reconstruction (ADR 0009/0028), used *descriptively*, not as a model input; the **prior council result**; **derived competitiveness facts** such as the last winning margin and "both candidates have previously won this ward", which convey the shape of a race without a verdict; the **CDI exposure triggers** for incumbents in the house voice ("↑ raises vulnerability — won with under 35%"), as directional watch-list cues and never odds; an **honest base-rate frame** (Toronto incumbents rarely lose — ~6% in normal cycles); and **raw ward polling where it exists** (ADR 0037), which for 2026 is essentially empty. The card is rich for the handful of legible races — an incumbent-vs-former-incumbent contest like University-Rosedale (Saxe's 123-vote 2022 win vs Layton's 69.6% 2018 hold) — and honestly sparse for the rest. It never classifies a race as Safe/Competitive/Open beyond the factual Open-Seat property (ADR 0036).

The consequence is a much smaller v1 than the mayoral arc. Because it publishes **no predictive quantity**, it **bypasses the entire forecast apparatus**: no council qualification ladder, no C-tier gate composition (ADR 0025), no whole-cycle forecast evaluation (ADR 0026) — there is nothing to gate or validate that the source project has not already validated as a screen. The probabilistic Council Forecast designed in ADR 0009/0012/0019/0025/0026/0027 is **not reversed** — it is **deferred** behind genuinely new signal (challenger strength — tested and null here; fundraising — not published during the campaign; open-seat structure), to be reopened only when such signal is acquired and evaluated as a new model version (ADR 0005). Statistical independence from the Mayoral Forecast (ADR 0014) is preserved and, via the coattail probe, reaffirmed. The Officeholding-History reconstruction (ADR 0009/0028) is still built — now scoped for description rather than prediction, which is where, in a data-scarce non-partisan council, it earns its keep.
