# Freeze publication gates by model version

Publication Gates, evaluation metrics, Qualification Baselines, and thresholds will be fixed before the publishable 2026 forecast is evaluated. A race/evidence tier must appear in at least three distinct Held-Out Election Cycles before it can unlock a public quantity; row counts do not substitute for cycles. Poll-freshness windows and method-specific diagnostics are governance rules frozen with the version rather than tuned on 2026. The model ladder is kept small and pre-declared: every family that clears its Qualification Baseline, together with that simpler baseline, becomes a Mandatory Sensitivity Variant without an arbitrary near-best score tolerance. A later change creates a new model version and requires the complete historical evaluation to be rerun, preventing current-race results from influencing whether those same results qualify for publication.
