# Configure the endpoint reliability gate with comparator-anchored, noise-aware maxima

ADR 0030 requires the Mayoral Endpoint to clear "frozen broad reliability and overconfidence checks against a pre-declared simple polling comparator" before any mayoral quantity may publish, but left the numeric maxima deferred (`MAYORAL_ENDPOINT_ABSOLUTE_MAXIMUM_SCORES = None`, fail-closed). This configures them. The gate is a set of **proper-score maxima** — not a per-band coverage or calibration test, because ADR 0006 records that Toronto's small number of independent elections cannot demonstrate realized calibration, so a coverage test would measure something the doctrine already concedes is unmeasurable. The maxima are applied on the **regular-elections population** (the authoritative qualification population, ADR 0040); the all-elections figures are reported but do not gate. The metric set is **`winner:log_score`** (the overconfidence guard), **`binary:close_result:brier`**, and **`shares:mean_candidate_crps`** — the overconfidence guard plus the broad reliability of the other two published quantities. Incumbent-defeat is excluded (Not Applicable in open races and base-rate-dominated across the three incumbent cycles, all wins), and the primary winning-margin CRPS is not re-asserted here because the relative arm already requires the endpoint to beat the comparator on it.

Each maximum is **comparator-anchored and noise-aware**: `maximum = comparator_regular_aggregate + t(0.95, df=5) · SE(paired per-cycle bridge-minus-comparator difference)`. The endpoint fails a metric only if it is worse than the pre-declared comparator by more than a one-sided 95% t-bound on cycle-to-cycle noise (n=6 cycles). Comparator-anchoring is the anti-tuning discipline: the comparator's scores exist independently of the endpoint, so no threshold is reverse-engineered to let the bridge pass; hand-set absolutes at this sample size would be arbitrary. The noise floor is the deliberate softening of a strict `≤ comparator` rule — a strict rule would veto the bridge on a close-result difference of +0.08 SE (pure noise) and a share difference of +0.95 SE (within noise), degradations n=6 cannot distinguish from zero. This noise floor is *not* the "conventional significance test" ADR 0030 warns against: that warning governs the *relative* qualification decision, which stays a conservative governance rule (the endpoint must genuinely beat the comparator on the margin); the floor here only gates the *absolute degradation* check, where refusing to fail on unmeasurable differences is the honest choice. The numbers are frozen literals (2026-08-19), not recomputed per run, per ADR 0005's requirement that gates be fixed before the 2026 forecast; the derivation is reproducible from the per-cycle scores:

```
winner:log_score            = 0.187679 + 2.015048 * 0.026463 = 0.241002
binary:close_result:brier   = 0.055497 + 2.015048 * 0.009497 = 0.074634
shares:mean_candidate_crps  = 0.004428 + 2.015048 * 0.000291 = 0.005014
```

The consequence is that the firm-balanced bridge **qualifies** for the first time: on the regular population it clears both the relative criteria (ADR 0030, 0040) and every reliability maximum (observed 0.16546 / 0.05627 / 0.00471 against 0.24100 / 0.07463 / 0.00501), so it is now the authoritative operative mayoral specification over the latest-sample comparator. This publishes nothing — Probability Band stability (ADR 0018), the Evidence Tier and publication gates (ADR 0033, 0005, 0003, 0032), and the Final-Ballot gate (ADR 0002) are unbuilt, and the whole publication layer still stands between qualification and any public quantity. The incumbency-informed variant still does not qualify over the bridge and remains the Mandatory Sensitivity Variant (ADR 0039). The pass is not tuned: it holds because the bridge's only degradations (close-result +0.08 SE, shares +0.95 SE) fall inside a 95% noise band, and the D̄/SE ratios are documented so a reviewer can see the bridge was not lifted over a reverse-engineered bar. Reproduced by `scripts/evaluate_mayoral_endpoint.py`; the gate is pinned by `test_endpoint_reliability_gate_is_configured_and_the_bridge_qualifies`.
