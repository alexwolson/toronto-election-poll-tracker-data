# Require Probability Band stability

A forecast quantity may publish only when every Mandatory Sensitivity Variant places it in the same Probability Band. The frozen set includes applicable prior-population or strength variants, low/base/high candidate-tail assumptions, leave-one-sample-out, leave-one-pollster-out, every pre-declared model family that clears its Qualification Baseline, and that family's simpler authoritative baseline. No arbitrary near-best score tolerance is used to omit a qualified family. A variant that cannot run fails the gate and cannot be silently omitted. For every variant, a two-sided 99% numerical or Monte Carlo error interval must also lie wholly inside the same half-open band; computation should run longer where possible, but a remaining boundary touch makes the quantity Forecast Unavailable. The preferred specification cannot override disagreement. This fail-closed rule sacrifices availability, especially near band boundaries, to make public hesitancy operational rather than editorial.

**Amended by ADR 0048.** One structural exception to "a variant that cannot run fails the gate": leave-one-pollster-out is Not Applicable — omitted from the Mandatory set, not a failure — when the qualifying evidence has fewer than three distinct pollsters, because dropping any one leaves too little to refit. This is narrow and cannot mask a disagreement; a variant that runs and lands in a different band, or that cannot run for any other reason, still fails.

**Amended by ADR 0049.** "The same Probability Band" is evaluated on a ladder of grids, finest first: the out-of-ten grid of ADR 0006, then the coarser out-of-five grid. The gate publishes the finest grid on which every variant lands in one band with its 99% interval inside, and is Forecast Unavailable only when no grid holds. The consensus-and-interval test is identical on each grid, so this stays fail-closed — it publishes a coarser but true statement instead of nothing when the fine grid is straddled, and still withholds a quantity whose variants disagree at every resolution.
