# Leave-one-pollster-out is Not Applicable below three pollsters

The Band Stability Gate (ADR 0018) requires every Mandatory Sensitivity Variant to place a quantity in the same Probability Band, and treats a variant that cannot run as a gate failure — fail-closed, so a quantity whose robustness cannot be fully checked is withheld. The **leave-one-pollster-out** variant drops each pollster in turn and refits the endpoint. When the qualifying (final-field) evidence has fewer than three distinct pollsters, dropping any one leaves fewer than two, which is below the endpoint's fitting floor — the refit returns no eligible evidence, so the perturbation cannot be evaluated at all.

This ADR **amends 0018**: leave-one-pollster-out is **Not Applicable** — omitted from the Mandatory Sensitivity Variant set rather than failing the gate — whenever the qualifying evidence has fewer than three distinct pollsters. It is a *structural inapplicability*, exactly analogous to Incumbent-Defeat Probability being Not Applicable in an open-seat race (ADR 0003), not a sign of a fragile forecast.

The exception is deliberately narrow so it can never mask a real disagreement. Only this one structural condition — pollster count below three — skips only this one variant. Everything else in ADR 0018 stands unchanged: a variant that runs and lands in a *different* band still fails the gate; a variant that cannot run for any *other* reason still fails; and the rest of the Mandatory set (the qualified model family and its simpler baseline, the low/base/high candidate-tail assumptions, leave-one-sample-out, and the incumbency variant) applies in full. The gate stays fail-closed everywhere the perturbation is assessable.

The reasoning rests on a distinction the gate must not blur. Model **qualification** (ADR 0030) establishes that the model itself is reliable, on the historical corpus. Band **stability** is a separate, live check: does *this* forecast survive perturbing *this* evidence? Leave-one-pollster-out asks whether the answer holds when any single pollster is removed — a question that only has meaning when at least three pollsters remain to drop one from. Below that threshold the check is not "failed," it is unaskable, and a qualified forecast should not be withheld on a robustness question the evidence structure cannot pose. It publishes, if it publishes, on the still-strong remainder of the suite.

**Consequence.** A two-pollster final-field corpus — the current Toronto 2026 evidence is Liaison and Forum — evaluates band stability across the applicable variants and may publish when they agree; a third pollster's final-field poll restores leave-one-pollster-out automatically, with no code or gate change. This does not touch the tier floors or the historical unlock (ADR 0005); it refines only which sensitivity variants are Mandatory for a given evidence structure.
