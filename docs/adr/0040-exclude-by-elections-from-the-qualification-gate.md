# Exclude by-elections from the qualification gate

The Mayoral Endpoint qualification (ADR 0030) evaluates two populations built by `evaluate_with_regular_election_sensitivity`: `all_elections` and `regular_elections_only` (`election_type == "general"`). The overall gate previously required *both* populations to qualify. This decision makes the **regular-elections-only population authoritative**: `MayoralEndpointQualification.qualifies` tracks `regular_elections_only.endpoint_qualifies` alone, and the `all_elections` decision is retained, computed, and reported but is **report-only**. A mayoral by-election is structurally unlike a general election — the 2023 contest was an open field triggered by a mid-term resignation, with 102 certified candidates and a compressed campaign — and that difference is already a first-class fact in the corpus (`election_type`), not a post-hoc label invented for this decision. Judging a general-election forecast against a by-election penalises the model on a regime it is not built for; the by-election is kept in full view as a reported sensitivity rather than deleted.

On the six-cycle 2006–2023 corpus this changes which comparison is decisive but not the published status. On the five regular cycles (2006/2010/2014/2018/2022) the firm-balanced bridge now meets ADR 0030's relative criteria — majority-of-cycles improved (3/5) and better aggregate winning-margin CRPS (0.0397 vs 0.0446), log-loss not worse — so `relative_qualifies` is true there for the first time. The endpoint nonetheless remains **`not_qualified`**, because the absolute reliability gate stays fail-closed: `MAYORAL_ENDPOINT_ABSOLUTE_MAXIMUM_SCORES` is `None`, so `endpoint_reliability.configured` is false and `endpoint_qualifies` is false regardless of population. Configuring that reliability maximum is a separate, still-deferred decision; this ADR does not touch it, and nothing here should be read as the endpoint having qualified.

Adversarial note, recorded so it is not lost: deciding to drop the by-election immediately after observing that it dragged the all-elections aggregate is a post-hoc selection risk. It is admissible here only because the by-election/general distinction is a genuine pre-existing structural taxonomy rather than a data-driven cut, the excluded cycle stays fully reported (never hidden), and the change does not itself manufacture a qualification. The result also remains an n=5/6 finding: the regular-elections pass rests on a 3/5 majority that a single cycle could flip, so it is reported, not tuned to (ADR 0030). Reproduced by `scripts/evaluate_mayoral_endpoint.py`; the gate semantics are pinned by `test_qualification_gate_excludes_by_elections`.
