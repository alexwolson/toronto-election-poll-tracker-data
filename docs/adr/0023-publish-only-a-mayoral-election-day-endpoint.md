# Publish only a Mayoral election-day endpoint

Each Mayoral Forecast is an election-day Internal Outcome Distribution indexed by an explicit Analysis Cutoff. It is not a measure of current support and does not publish a predicted path of support between the cutoff and election day; the Polling Estimate carries the descriptive current-opinion role. A chosen model may contain temporal states internally, but their existence, model family, and computational toolkit are implementation questions that must be earned through historical evaluation rather than part of the public claim.
