# Publish the finest stable Probability Band

The Band Stability Gate (ADR 0018) publishes a quantity only when every Mandatory Sensitivity Variant lands in the same Probability Band, on the out-of-ten grid of ADR 0006. On a two-pollster final-field corpus that grid is unforgivingly fine: perturbations that are substantively small — a variant at "about 4 in 10" against a consensus of "about 3 in 10" — straddle an adjacent ten-point boundary and force Forecast Unavailable, even when the same variants agree completely at any coarser resolution. The result withholds a robust statement ("Chow is the clear favourite") because the evidence cannot pin it to a *ten-point* band, not because the finding is fragile.

This ADR adds a **coarse out-of-five grid** and makes the gate publish the **finest band on which the variants agree**. Grids, finest first:

1. **Out-of-ten** — ADR 0006 verbatim, eleven half-open bands, "N in 10" wording.
2. **Out-of-five** — six half-open bands (0–<10% "less than 1 in 5", 10–<30% "about 1 in 5", 30–<50% "about 2 in 5", 50–<70% "about 3 in 5", 70–<90% "about 4 in 5", 90–100% "more than 4 in 5"), "N in 5" wording. Frozen (ADR 0005), like the out-of-ten grid.

**Gate rule.** For each grid in order, test the ADR 0018 consensus condition: every variant lands in the same band *and* each variant's two-sided 99% error interval lies wholly inside it. Publish the first grid that holds, at its band and Frequency Statement. If no grid holds — the variants straddle even the coarse out-of-five boundary — the quantity is Forecast Unavailable, exactly as before. The out-of-five grid is a *fallback*, never a relaxation: a quantity that clears the out-of-ten grid still publishes at ten-point resolution.

This preserves everything ADR 0018 exists to protect. The gate is still fail-closed (ADR 0032): the coarse grid can only be *reached* after the fine grid fails, and it applies the identical consensus-and-interval test, so a genuinely unstable quantity — one whose variants disagree at every resolution — is still withheld. It does not touch the tier floors or the historical unlock (ADR 0005/0032), and each quantity is still gated independently (ADR 0003). The out-of-five bands are a presentation rule, not a claim of measured per-band calibration, on the same footing as the out-of-ten grid (ADR 0006). The two structural exceptions already in force — Not-Applicable variants (ADR 0003 open-seat Incumbent-Defeat, ADR 0048 leave-one-pollster-out below three pollsters) — compose unchanged: they decide *which* variants are Mandatory before the grid ladder runs.

This ADR **amends 0006** (adds the coarse out-of-five grid alongside the out-of-ten grid) and **amends 0018** (the gate publishes the finest agreeing grid rather than requiring the out-of-ten grid). ADR 0018's core discipline — same band, 99% interval strictly inside, a variant that cannot run fails, no near-best tolerance — is unchanged; it now runs per grid, finest first.

**Consequence.** On the certified Toronto 2026 final-field evidence (Forum + two Liaison waves, three final-field samples → M3), the gate publishes four of five quantities: Alexander's win at the *ten-point* band 0–<5% ("less than 1 in 10", where the variants already agreed finely), and Chow's win (70–<90%, "about 4 in 5"), Bradford's win (10–<30%, "about 1 in 5"), and Incumbent-Defeat (10–<30%, "about 1 in 5") at the out-of-five fallback. Close-Result stays Forecast Unavailable: its variants range across [~0.18, ~0.31] and straddle the 0.30 out-of-five boundary, so no grid holds — the finding is genuinely unstable and is correctly withheld. As the final-field corpus grows and the variants tighten, quantities migrate back to the ten-point grid with no code or gate change.
